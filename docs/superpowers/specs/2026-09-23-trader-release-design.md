# Trader research release

User approved priorities 1–4 and requires actual data only. Extend existing models, snapshot store and collector; do not introduce a paid service.

1. Explicit price-only (price and observed volume), derivatives (funding and OI), and derivatives plus on-chain (MVRV and net flows) configurations. Fixed feature lists; SOPR is not silently required or imputed. Price-only is the explicit default, not an automatic fallback. Historical model availability is distinct from latest feature completeness.
2. Data health reports original observation dates where available, latest usable market-aligned dates, missing rows, provider, receipt time, collection errors and last classified date for each model. Operational freshness thresholds are policies, not market observations.
3. Evidence cards use existing nonoverlapping 7/14/30-day event ledgers, same eligible-date unconditional benchmark, descriptive mean difference, counts, sampled distinct episodes and observed bootstrap intervals. No calibrated probabilities or significance claims. Unavailable and unclassified states remain explicit.
4. Collector freezes a numerical scaler/centroid artifact per venue and feature set at first registration, with a permanent model ID and input snapshot version. Future runs never refit that artifact. Record only the latest observed completed bar once per model/date; no historical prediction backfill. Schedule the first UTC open strictly after recording, then resolve 7/14/30-day gross open-to-open outcomes only from later actual completed bars. These are timestamped paper research observations, not fills, net P&L or a validated investment strategy. No assumed fees, execution prices, premiums or costs. Preserve prediction fields and completed outcomes across revisions; attach outcome snapshot versions. Retain prior good data on missing input/failure.

Remove assumed-premium and cost/slippage scenario displays. Reject explicitly synthetic or unverified uploaded market inputs in production. Actual historical revisions and the on-chain 48-hour alignment policy remain disclosed. Software robustness tests may invalidate a copy of a real fixture; no fixture is a market claim.

Verify frozen artifacts, no backdating, no duplicate predictions, no future leakage, missing observations, stable resolved outcomes, source integrity, bilingual UI and deployed collection. Existing historical walk-forward fits remain exploratory; forward artifacts are a separate evidence stream. Frozen protocol: standardized four-cluster KMeans (seed 42), minimum 180 complete rows, label by centroid momentum; no automatic parameter search.
