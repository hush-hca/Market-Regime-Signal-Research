# Regime Atlas — 시장 국면 분석 대시보드

[English](README.md) · [실제 운영까지의 다음 단계](docs/roadmap.ko.md)

BTC의 가격·펀딩비·미결제약정으로 시장 국면을 분류하고, 이후 수익률 분포와 규칙 기반 전략의 결과를 확인하는 Streamlit 리서치 도구입니다.

**사이드바의 `Language / 언어`에서 `한국어`를 선택하세요.** 화면, 지표 설명, 표, 차트와 주요 오류 안내가 한국어로 바뀝니다. 언어 전환 시 선택한 설정은 유지됩니다. CSV 열 이름과 분석 기록의 식별자는 재현성과 호환성을 위해 영어로 유지합니다. Streamlit 자체 파일 업로드·차트 도구 등의 일부 기본 버튼과 외부 라이브러리의 기술 상세는 영어로 표시될 수 있습니다.

## 실행

Python 3.12 환경에서 저장소 폴더로 이동한 후 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

기본 화면은 Bybit BTCUSDT의 마감된 일봉·펀딩비·제공 가능한 OI를 자동 조회합니다(730일). 결과는 최대 1시간 캐시하며 **거래소 데이터 새로고침**으로 즉시 재조회할 수 있습니다. API 접근에 실패하면 출처가 확인된 실제 저장 데이터가 있을 때만 원래 기준일 및 경고와 함께 표시하고, 없으면 오류를 표시합니다. 가상 데이터 선택 항목과 자동 대체는 없습니다. 서버의 외부 API 접근 또는 아래 명령으로 저장한 데이터가 필요하며, 거래소의 지역 제한이 적용될 수 있습니다.

실제 데이터를 저장하려면:

배포 이미지에는 **2026-09-17 UTC까지의 실제 Bybit 일봉 730개**도 포함합니다. API 조회에 실패하고 로컬 저장 데이터가 없으면 이 과거 스냅샷을 사용합니다. 화면에 실패 경고와 원래 기준일을 표시하며 실시간 데이터로 취급하지 않습니다. `bootstrap/bybit.json`에 출처·수집 시각·파일 무결성 해시가 기록되어 있습니다.

```powershell
python -m regime.ingest --venue bybit --days 730
```

이후 사이드바에서 **저장된 데이터**를 선택합니다. 또는 **공개 API에서 가져오기**를 선택해 수집할 수 있습니다. 기본 모델은 가격과 펀딩비를 사용합니다. 충분한 OI 이력이 있으면 **미결제약정(OI) 지표 포함**을 선택하세요. Binance 기본 OI API는 최근 이력만 제공하므로 긴 기간의 OI 분석에는 별도 데이터가 필요합니다.

## 문제 정의

지표의 높고 낮음을 보여주는 것을 넘어, 비슷한 상황 이후 어떤 결과가 나타났는지 표본 수와 불확실성까지 확인하는 것이 목적입니다. 자동매매 시스템은 아닙니다.

## 가설

- 가격·펀딩비 특성으로 반복되는 시장 상태를 구분할 수 있는가?
- 각 상태의 이후 7일·14일·30일 수익률 분포가 다른가?
- OI와 온체인 지표가 기본 모델보다 추가 정보를 제공하는가?

군집은 상태를 설명하며 미래 상승을 보장하지 않습니다. 음의 펀딩비와 낮은 MVRV만으로 자금 유입을 입증할 수 없습니다.

## 데이터

공개 Binance/Bybit API에서 BTCUSDT 무기한 선물 일봉, 펀딩비, 제공 가능한 OI를 수집합니다. 원본 응답과 조회 시각을 저장하고 중복 날짜, 누락 날짜, 비정상 가격을 검증합니다. 원본 데이터와 인증정보는 Git에 포함하지 않습니다.

온체인 CSV는 `available_at`과 `mvrv`, `sopr`, `exchange_netflow` 중 하나 이상을 포함해야 합니다. `available_at`은 해당 값이 실제로 공개된 시각이어야 합니다. 관측일만 보고 결합하면 미래 정보가 섞일 수 있습니다. 제공처의 과거 수정 내역과 이용 권한은 별도로 확인해야 합니다.

## 검증

- 초기 365일 이후 과거 데이터만으로 표준화·군집화합니다.
- 90일마다 재학습하고 마지막 180일에는 모델을 고정합니다.
- 신호 생성 다음 날 시가에 진입합니다. 관찰 구간끼리 겹치지 않도록 표본을 추출합니다.
- 수익률 평균·중앙값·분위수·상승 빈도·근사 신뢰구간·표본 수를 함께 표시합니다.
- 전략 손익에는 설정한 수수료, 슬리피지, 선택 시 일별 펀딩비를 반영합니다.
- `python -m pytest -q`로 계산 시점, 비용, 데이터 누락, 화면 및 언어 전환을 검증합니다.

## 한계

180일에서 독립적으로 활용할 수 있는 월 단위 표본은 매우 적습니다. 최종 평가 결과를 보고 설정을 바꾸면 새 기간으로 다시 검증해야 합니다. 공개 API의 현재 이력은 당시 공개된 값과 다를 수 있습니다.

현물 유사 모드는 선물 가격을 사용하는 대용치이며 실제 현물 체결 백테스트가 아닙니다. 옵션 페이지는 가정 프리미엄을 사용한 만기 손익 시뮬레이션입니다. 과거 옵션 전략의 실현 수익률을 제공하지 않습니다.

자동 갱신·운영 모니터링·유료 온체인 API 연결·실제 과거 옵션 호가 백테스트·운영 서버 배포는 아직 구현하지 않았습니다. 자세한 조건과 우선순위는 [로드맵](docs/roadmap.ko.md)을 확인하세요.
