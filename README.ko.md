# Regime Atlas

[English](README.md) · [대시보드](https://market-regime-research-choas-projects-d5c2c283.vercel.app/)

실제 거래소·온체인 관측을 사용하는 BTC 시장 국면 연구 도구입니다. 화면에 가상 데이터, 가정 프리미엄, 임의 수수료·슬리피지 결과, 만들어낸 전진 수익률을 표시하지 않습니다.

## 문제 정의
시장 상태 설명과 검증된 거래 우위를 구분합니다. 모델 입력, 최신성, 과거 결과의 표본 수와 불확실성, 등록 후 전진 관측 기록을 함께 확인합니다.

## 가설
가격·파생상품·온체인 특성으로 이후 결과가 다른 상태를 구분할 수 있는지 연구합니다. 예측력이나 수익성이 입증된 것은 아닙니다. 음수 펀딩비와 낮은 MVRV가 자금 유입을 입증하지 않습니다.

모델을 직접 선택합니다. 기본 **가격만** 모델은 가격 모멘텀·변동성·거래량을 사용합니다. **가격 + 파생상품**은 펀딩비·OI를, **가격 + 파생상품 + 온체인**은 MVRV·순유입을 추가합니다. SOPR은 포함하지 않습니다. 입력이 빠지면 미분류로 남기며 모델을 자동 대체하지 않습니다.

## 데이터
GitHub Actions가 실제 관측을 시간별로 수집하여 `research-data` 브랜치에 체크섬과 함께 저장합니다. Binance API가 실패하면 공식 공개 아카이브의 실제 가격·OI·월별 펀딩비를 사용합니다. 펀딩비 게시 지연을 숨기지 않습니다. 데이터 상태 표는 원래 관측일, 모델에 사용 가능한 날짜, 수집 시각, 누락, 오류를 구분합니다. 관측 후 3일 초과 시 오래된 데이터로 표시하는 운영 기준입니다.

Coin Metrics의 실제 MVRV·순유입은 비상업 연구용 CC BY-NC 4.0 조건입니다. 과거 수정 가능성이 있으며 48시간 온체인 정렬 지연은 최초 공개 시각이 검증된 값이 아닌 명시적 연구 정책입니다. 옵션 탭에는 실제 Deribit 호가만 표시합니다. 출처를 검증할 수 없는 CSV 업로드와 가정 손익 곡선은 비활성화했습니다.

## 검증
과거 모델은 365일 준비 기간 후 과거 데이터만으로 학습하고 90일마다 재학습합니다. 마지막 180일은 모델 고정 구간이지만 이미 확인한 탐색적 평가입니다. 국면별 근거 카드에는 완료 표본, 표본 국면 발생 횟수, 평가 구간, 평균·중앙값·양수 빈도, 동일 적격 날짜 기준 평균과 차이가 표시됩니다. 5개 미만이면 불확실성 구간을 표시하지 않고 30개 미만이면 표본 부족으로 표시합니다.

**전진 모의 관측 원장**은 최초 등록 때 모델과 특성 정의를 고정합니다. 실제 기록 이후 관측만 추가하며 과거 예측을 소급 생성하지 않습니다. 규칙은 입력이 완전하고 실제 30일 모멘텀이 양수이면 매수, 그 외에는 관망입니다. 기록 후 첫 UTC 시가를 진입 기준으로 예약합니다. 실제 후속 봉이 수집되어야 7·14·30일 결과를 계산하고 완료된 결과는 변경하지 않습니다. 실제 체결 기록이 아니며 수익률은 펀딩비·수수료·슬리피지·이자를 제외한 선물 봉 가격 변동입니다. 겹치는 전진 구간은 독립 표본이 아닙니다.

실행: Python 3.12에서 `pip install -r requirements-lock.txt`, `streamlit run app.py`. 검증: `python -m pytest -q`. [운영 문서](docs/operations.md)와 [전진 프로토콜](docs/forward-protocol.md)을 참고하세요. 화면 테스트는 검증된 실제 저장 데이터를 사용하며, 수학 단위 테스트용 자료는 운영 데이터나 시장 근거로 사용하지 않습니다.

## 한계
거래 우위는 입증되지 않았습니다. 저장된 보고서의 월별 독립 관측은 특성 조합당 5개뿐입니다. SOPR, 실제 체결·비용 증거, 충분한 과거 옵션 호가 및 전진 성과 축적은 미완료입니다. API 접근 제한·월별 펀딩비 지연·GitHub 일정 지연이 발생할 수 있습니다. 자동 주문이나 유료 인프라는 없습니다.
